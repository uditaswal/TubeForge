# Channel safety implementation plan

1. Disclosure: show source, originality and audio-rights evidence for each job and bind the operator's disclosure decision to the exact reviewed artifacts. Acceptance: authenticated approve/stage tests reject missing evidence and stale approvals; inspect an existing final and the review UI. Evidence: focused test results and real-job inspection. No script generation or publication.
2. Repetition: expose structured comparisons for recent shorts, including hook/opening, title, phrases, layout, music and voice. Acceptance: deliberately repetitive fixtures and day/week/channel isolation tests; inspect the report for existing jobs. No claims about monetization or predicted views.
3. Cadence: configurable per-channel daily volume and minimum spacing warnings at import and review. Acceptance: timezone, boundary, missing-time and cross-plan tests. Publish dates remain operator metadata; no scheduling or platform calls.
4. Checklist: a short public operator checklist linked from review and batch documentation. Acceptance: links resolve and no local paths or secrets appear.

Provider routing is a separate phase and requires the operator's explicit OK before implementation. M4 and design tokens remain outside these checkpoints.
